# タスク概要
`test_ocr.py` の挙動を参考に、Rust 製の実行可能バイナリを追加して推論パイプラインを動作確認できるようにする。

## 要件
- `OcrEngineBuilder` を利用し、既存のモデル・辞書を読み込んで単一画像に対して OCR を実行する CLI を追加する
- デフォルトで `models/ppocrv5` 配下の資産を参照しつつ、コマンドライン引数でパスや設定を上書きできるようにする
- 推論所要時間や検出結果のテキスト・信頼度・ポリゴン座標を整形して標準出力に表示する
- 入力画像が見つからない、モデルが読み込めないなどの失敗時に、原因を含むエラーメッセージと非ゼロ終了コードを返す
- `cargo test` 実行時に安全にスキップできるスモークテスト（例: フィクスチャが不足している場合は `#[ignore]`）を追加し、バイナリの基本的な呼び出しが失敗しないことを確認する

## 作業ログ
- `src/bin/ocr_smoke.rs` を追加し、CLIパーサ・タイミング計測・結果表示を含む Rust 製動作確認バイナリを実装
- `tests/ocr_smoke.rs` で `--help` 実行を検証する統合テストを追加し、バイナリのビルド可否を確認
- `README.md` に `ocr_smoke` の使用方法とモデルパス上書きオプションを追記
- DBNet 前処理を 32 ピクセル単位でパディングするよう更新し、`det.onnx` が要求する入力形状制約を満たすように修正
- バイナリ自体は動作するが OCR 結果が不正確なため、モデル・後処理のデバッグを今後の課題として残存
